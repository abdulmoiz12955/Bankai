# BANKAI — The Absolute Cutter  (Minecraft Java 1.20.1 · Forge 47.x · Java 17)

One legendary sword: silver aura, cuts trees/foliage (optional terrain mode), and a 5-second charged
black-and-gold **Getsuga** (full charge = 800 base damage; normal hit = 50).

## HONEST STATUS — read first
* **No .jar is included.** The environment this was written in has no internet, no Forge and no Gradle, so the mod
  could not be compiled or run. All Java was syntax-checked with javac only (no syntax errors; Minecraft symbols
  could not be resolved offline). **Nothing here has been tested in-game.** Expect to fix a few small API/name
  mismatches on first build — send me the error text and I will fix it.
* The .jar is produced by one command on your PC (below) and appears in `build/libs/absolute_cutter-1.0.0.jar`.
* Textures, model, particles and sounds ARE included (generated by `tools/generate_assets.py`, all original).

## Build the .jar (Windows / Mac / Linux)
1. Install **JDK 17** (e.g. Temurin 17). Check: `java -version` shows 17.
2. Download the **Forge 1.20.1 MDK** (47.3.0 or newer 47.x) from files.minecraftforge.net and unzip it somewhere.
3. Copy these from the MDK into this project folder (they are not included because they are binary):
   `gradlew`, `gradlew.bat`, and the whole `gradle/` folder (contains `gradle-wrapper.jar`).
4. In this folder run:
   * Windows: `gradlew.bat build`
   * Mac/Linux: `./gradlew build`
5. Your mod is `build/libs/absolute_cutter-1.0.0.jar`. (First build downloads ~1 GB, takes several minutes.)
   Test without installing: `gradlew runClient`.
If your Forge differs, change `forge_version` in `gradle.properties`.

## Install with SKlauncher
1. In SKlauncher choose **Forge 1.20.1** (47.x) → Play once so the Forge profile exists.
2. Press Win+R → `%appdata%\.minecraft\mods` (create `mods` if missing). Mac: `~/Library/Application Support/minecraft/mods`.
3. Drop `absolute_cutter-1.0.0.jar` in, launch the Forge 1.20.1 profile.
4. Get the sword: Creative tab **Absolute Cutter**, or `/give @s absolute_cutter:absolute_cutter`.
   Survival recipe: nether star ×3 (top, left, right) + netherite sword (centre) + netherite block (bottom).

## Controls
| Action | Result |
|---|---|
| Left-click / swing | normal hit (50 dmg via attribute) + cutting cone for trees, leaves, plants |
| Hold **V** + swing | optional terrain mode (rebind in Controls → "Absolute Cutter") |
| Hold right-click 5 s, release | full Getsuga (800). Earlier release = weaker shot (≥1 s) or cancel, per config |

Charge cues: 0–1 s thin silver aura · 1–3 s coils + black particles, deeper pitch · 3–5 s black/gold ring,
rising pitch, subtle FOV squeeze + camera tremor · 5 s flash + chime (audible "ready" cue).

## Files / config
* `config/absolute_cutter-common.toml` (gameplay, per world/server) and `config/absolute_cutter-client.toml` (visuals).
* All requested options exist: damage values, charge seconds, speed/width/range/lifetime, aura on/off + density,
  cutting radius + block cap, terrain destruction (off by default, budget-capped), entity exclusions, friendly fire,
  early-release mode, post-shot cooldown.
* Sounds: original synthesised `.ogg` in `assets/absolute_cutter/sounds/`. To swap, replace the files (same names).
  Fallback to vanilla sounds: edit `sounds.json` entries to `{"name":"minecraft:block.beacon.ambient","type":"event"}`.
* Regenerate every texture/model/sound: `python3 tools/generate_assets.py` (needs Pillow, numpy, ffmpeg).

## Design notes / deviations from the brief (and why)
* **Normal damage** is only the attribute (`configured − 1` on top of the player's 1.0 base = exactly 50). No event adds damage.
* **Charge is server-authoritative with zero custom packets**: vanilla "use item" duration is tracked by the server;
  `releaseUsing` computes the charge itself. Only the left-click swing uses one packet, and the server re-checks held
  item, cooldown, config and range.
* **Getsuga**: server-moved projectile entity, swept AABB vs entities every tick, once per target (dragon counts once),
  normal `hurt()` pipeline, caster always excluded. Blocks stop it (collider clip); terrain destruction is off by default
  and goes through the player's break event (protection plugins respected) with a hard block budget.
* **Cutting** uses `ServerPlayerGameMode.destroyBlock` (BreakEvent, loot, protection). Never touches bedrock,
  wither-immune blocks, block entities, liquids, unloaded chunks or outside the world border. Crops are skipped.
* **Item model**: vanilla JSON cuboid model (80 elements, own UVs, 64×64 atlas). Blade curvature is stair-stepped
  because vanilla models only allow 22.5° rotations. Hand/GUI display transforms were derived by maths from vanilla's
  handheld transforms and are **unverified by eye** — if the sword sits oddly in your hand, tweak the `display` block
  in `models/item/absolute_cutter.json` (rotation z / translation / scale).
* **Not implemented**: a true space-distortion shader around the edge (needs a custom shader pipeline; replaced by a faint
  reverse-portal shimmer particle). The "player surroundings distortion" is an FOV squeeze + camera tremor.
* Aura positions are approximations of the blade tip (no per-frame hand-bone tracking).
* Vanilla slows walking while an item is being used; an EXPERIMENTAL client option `chargeSlowdownFix` exists (off).
* Right-clicking a block that has its own use action (chest, door) does that instead of charging — vanilla rule.

## Test checklist
**Single-player**
- [ ] Mod loads, sword appears in creative tab, model looks right in first person, third person, GUI, item frame, dropped.
- [ ] Idle aura visible, pulses every ~3.5 s; turning `idleAura=false` removes it.
- [ ] Hit a zombie: tooltip/attack shows 50; silver flash on hit; no damage from just standing near the aura.
**Charging**
- [ ] Hold right-click: stage visuals at 1 s / 3 s, rising sound, flash + chime exactly at 5 s.
- [ ] Release at 5 s fires; release at 0.5 s does nothing; at 2.5 s fires smaller shot (WEAK_VERSION) / nothing (CANCEL).
- [ ] Scroll to another item mid-charge cancels; dying cancels; cooldown (2 s) blocks instant re-fire but not the next charge.
**Projectile / damage**
- [ ] Black crescent with gold rim and silver streaks, trailing smoke + sparks; flies where you look.
- [ ] Armored mob with 20 HP dies; mob with huge HP (set `fullDamage` low to test scaling) takes damage once, not per tick.
- [ ] Fast mob at 40 blocks is hit (no tunnelling). Caster never hurt. Tamed wolf safe unless `friendlyFire=true`.
- [ ] Hits a wall: impact flash/sound, no block damage by default. With `terrainDestruction=true`, bounded hole (≤ budget).
**Cutting**
- [ ] Swing at a tree + leaves: leaves/logs drop items normally, at most `maxBlocksPerSwing` per swing, cone only.
- [ ] Stone is untouched normally; hold V + swing cuts stone-hardness blocks (≤ 24); obsidian/bedrock/chests never.
- [ ] Inside a claimed/protected area (protection mod) nothing breaks.
**Multiplayer / dedicated server**
- [ ] Drop the jar in a dedicated server's `mods/`: server starts (no client class crash).
- [ ] Second player sees aura, charge FX, Getsuga, hears sounds. Spamming left-click faster than `swingCooldownTicks` is ignored.
- [ ] Modified client sending swings without holding the sword does nothing.
